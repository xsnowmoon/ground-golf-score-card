グラウンド・ゴルフ スコア記録ツール　説明
================================================

プログラム名：
　グラウンド・ゴルフ スコアカード（ground-golf-score-card.html）
　グラウンド・ゴルフ スコア管理表（ground-golf-score-manager.xlsx）
　作成：Snow Moon　Ver.20261115.1.0

プログラム内容：
　グラウンド・ゴルフの大会や練習会で、スコアを記録・集計するための道具です。
　2つのファイルがセットになっています。

　記録係が使う道具です。
　・スマホやタブレットのブラウザで動き、タップだけで入力できます
    アプリのインストール不要、オフラインでも動作
    ファイル名:ground-golf-score-card.html

　・1組6人まで、最大5周まで記録できます
　・公式ルール対応：ホールインワンは「①」表示で、合計から1回につき3打を引きます
　・スタートホール（ショットガン方式）、打ち止めルール、打順の表示に対応
　・入力漏れがあると進む前に知らせます
　・記録は端末に自動保存され、途中で閉じても続きから再開できます
　・結果は、公式書式のスコアカード（PDF印刷）、記録用CSV、結果テキストで出せます

　大会本部・運営が使う集計表です。
    ファイル名:ground-golf-score-manager.xlsx

　・各組から届いたCSVを貼るだけで、大会全体を集計します
　・公式書式のスコアカード、個人ランキング、チームランキングが自動で並びます
　・表彰用に、ホールインワン最多賞・2打回数最多賞・団体賞も自動で出ます
　・フリーの表計算ソフト（LibreOfficeなど）でも開けます

　・スコアカード（HTML）の記録は、お使いのブラウザの中に保存されます。

余談：
　・プログラムを作成した経緯
　　地域でグランドゴルフがあり、お手伝いで応援を2年した後、
    今度は記録係をお願いされました。※記録係の経験は、まだ1回だけです。

　　プレイしたことも無いし、ルールも良く分からないまま、
    スコア記録用紙に記入していましたが、運営側は記録用紙を記録係の所まで回収に来て、
    パソコンに手入力で集計し、結果を紙に書いて掲示していました。
　　ん～～、正直めんどくさい。

　　そもそもグランドゴルフに興味は無いし、ルールを覚えるのは面倒だし、日焼けするのも嫌だし……。
    どうせ年に1回しかやらないし、記録の方法なんて覚えていません。
　　始まりは、そんなところでした。

　　面倒なので、データで入力できたらいいな……。
    かと言って、オンラインで常時データを収集するほどのことでもないし……。
　　入力は、老眼でも見やすい、安い10インチくらいのタブレットが良いかな。
    OSに依存したくないから、ブラウザで動く方がいいな。
    スマホの中で直接PDFで出せたら見やすいかも？　
    さらには、表計算ソフトで集計できたら楽かも？
　　と色々機能を追加していたら、このプログラムが出来ました。
